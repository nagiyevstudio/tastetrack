# 🍽️ Taste Track - Трекер питания

## Описание

**Taste Track** — это веб-приложение для отслеживания вашего рациона и контроля питания. Приложение помогает пользователям вести дневник съеденных продуктов, отслеживать калории и другие пищевые характеристики.

## 🎯 Возможности

- **Отслеживание продуктов** — добавляйте съеденные блюда и напитки в ваш дневник
- **Анализ питания** — просматривайте информацию о калорийности и составе продуктов
- **История питания** — сохраняйте историю своего рациона по дням
- **Локальный режим** — если сервер недоступен, данные автоматически сохраняются в браузер
- **PWA поддержка** — работает как веб-приложение, установляемое на устройство

## 🛠️ Технический стек

| Компонент | Технология |
|-----------|-----------|
| **Frontend** | React + Vite (TypeScript) |
| **Backend** | PHP (REST API) |
| **База данных** | MySQL |
| **Аутентификация** | Cookie-based PHP sessions |

## 🔐 Безопасность

- **HttpOnly Cookies** — защита от XSS атак
- **SameSite Policy** — защита от CSRF атак
- **Rate Limiting** — ограничение неудачных попыток входа по IP
- **Single Password Auth** — единая парольная защита приложения

## 📱 Функции

- Автоматический переход в локальный режим при недоступности сервера
- Поддержка PWA (Progressive Web App)
- Кроссплатформенность (браузер, мобильные устройства)
